# Fase 87 — decisão humana sobre simulação

O Atlas registra a decisão da diretoria sobre uma simulação: aprovada apenas para planejamento, rejeitada ou devolvida para revisão. A decisão exige referência do revisor, motivo e data em formato auditável.

Mesmo quando aprovada para planejamento, a decisão não autoriza execução. O Atlas não altera orçamento, público, campanha ou produção e não inclui dados de clientes, payloads de provedores ou segredos.

```bash
node scripts/preflight-meta-simulation-decision.mjs --self-test
```
