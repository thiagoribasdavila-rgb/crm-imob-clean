# Fase 85 — solicitação de revalidação

Quando a gestão pede mais evidência, o Atlas registra uma solicitação humana com motivo classificado. A revalidação exige nova proveniência e nova aprovação; evidência ou memória anterior não podem ser reaproveitadas como atalho.

A solicitação não inicia teste externo, não altera campanhas ou produção e não inclui payload, segredos ou dados de clientes.

```bash
node scripts/preflight-meta-learning-revalidation-request.mjs --self-test
```
