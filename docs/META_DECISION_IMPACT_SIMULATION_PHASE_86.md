# Fase 86 — simulação de impacto para decisão

O Atlas pode mostrar cenários antes de uma decisão de marketing: tipo de mudança, faixa de impacto e confiança. Todo cenário é uma estimativa e exige revisão humana; confiança baixa obriga impacto “desconhecido”.

O simulador não altera orçamento, público, campanha ou produção e não utiliza payload, segredos ou dados de clientes.

```bash
node scripts/preflight-meta-decision-impact-simulation.mjs --self-test
```
