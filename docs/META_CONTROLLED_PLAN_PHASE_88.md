# Fase 88 — plano controlado de marketing

Uma decisão aprovada para planejamento pode gerar um plano controlado: objetivo, hipótese, métrica de sucesso, janela de revisão e responsável. O plano fica em rascunho para revisão humana e preserva o vínculo auditável com a decisão anterior.

O plano não autoriza execução, mensagens de saída, alterações de orçamento, público, campanha ou produção. Ele não recebe dados de clientes, payloads de provedores ou segredos.

```bash
node scripts/preflight-meta-controlled-plan.mjs --self-test
```
