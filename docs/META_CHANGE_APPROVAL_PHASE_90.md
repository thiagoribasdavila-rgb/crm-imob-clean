# Fase 90 — aprovação humana de mudança

O Atlas exige dois revisores independentes, motivo e prazo de validade para registrar uma aprovação de mudança. A aprovação pode liberar somente a preparação controlada; ela nunca é uma autorização automática de execução.

O registro não altera orçamento, público, campanha ou produção e não armazena dados de clientes, payloads de provedores ou segredos.

```bash
node scripts/preflight-meta-change-approval.mjs --self-test
```
