# Fase 368 — Prontidão do contexto comercial da IA

## Objetivo

Medir se a memória comercial estruturada já contém os quatro elementos mínimos para apoiar uma decisão útil: projeto, etapa canônica, responsável e próxima ação válida.

## Fonte canônica

A leitura usa exclusivamente `lead_commercial_memory_states`, sempre filtrada pela organização autenticada. O diagnóstico não consulta mensagens, nomes, telefones, e-mails ou qualquer texto de conversa.

## Regras

- acesso consolidado exclusivo para administrador e diretor;
- leitura limitada a 5.000 estados, com aviso explícito quando parcial;
- etapa validada pelo funil canônico do Atlas One;
- próxima ação validada pela taxonomia já aplicada no banco;
- cobertura completa não significa precisão preditiva;
- nenhuma ação, distribuição ou atualização é executada pelo diagnóstico;
- toda recomendação futura permanece sujeita a revisão humana.

## Evidência de homologação pendente

Após publicação, autenticar como diretor, abrir a saúde do WhatsApp e confirmar que a seção da Fase 368 mostra somente agregados da organização correta. Uma conta sem memória deve retornar zero, sem erro e sem dados de outra organização.
