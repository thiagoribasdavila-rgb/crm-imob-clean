# Fase 72 — régua de confiança do aprendizado

O Atlas classifica qualidade, amostra, atualidade e contradições antes de apresentar uma recomendação. Evidência insuficiente ou vencida não vira recomendação; contradições entram em modo de monitoramento.

Mesmo uma recomendação válida exige aprovação humana. A régua não altera campanhas, públicos, orçamento, eventos da Meta ou produção e não usa payload, segredos ou dados de clientes.

```bash
node scripts/preflight-meta-learning-confidence.mjs --self-test
```
