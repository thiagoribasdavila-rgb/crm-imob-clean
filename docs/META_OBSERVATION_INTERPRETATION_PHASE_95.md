# Fase 95 — interpretação humana da observação

O Atlas exige que uma pessoa responsável interprete a observação agregada, informe uma conclusão, nível de evidência e próximo passo. Evidência insuficiente obriga a coleta de mais evidências; nenhuma variação é convertida em causalidade automaticamente.

A interpretação não solicita otimização nem altera orçamento, público, campanha ou produção. Não utiliza dados de clientes, payloads de provedores ou segredos.

```bash
node scripts/preflight-meta-observation-interpretation.mjs --self-test
```
