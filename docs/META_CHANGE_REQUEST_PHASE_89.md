# Fase 89 — solicitação formal de mudança

O Atlas separa planejamento de execução por uma solicitação formal de mudança. Ela referencia o plano, delimita classe e escopo, identifica quem solicitou, explica o motivo e fica pendente de aprovação humana.

O pedido não aprova nem executa alterações. Não muda orçamento, público, campanha ou produção e não contém dados de clientes, payloads de provedores ou segredos.

```bash
node scripts/preflight-meta-change-request.mjs --self-test
```
