# Fase 73 — briefing para decisão humana

O Atlas converte uma análise com confiança em briefing para a diretoria: pergunta de decisão, classe de evidência, nível de confiança, limite conhecido e ação humana sugerida.

Confiança baixa exige mais evidência. O briefing não aprova mudanças e não altera campanhas, públicos, orçamento ou produção. Também não inclui payload, segredos ou dados de clientes.

```bash
node scripts/preflight-meta-learning-decision-brief.mjs --self-test
```
