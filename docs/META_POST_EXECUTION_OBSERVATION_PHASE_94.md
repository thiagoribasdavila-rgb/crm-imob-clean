# Fase 94 — observação pós-execução

O Atlas prepara uma observação agregada do período antes e depois de uma execução manual: métrica, linha de base, valor observado, janela e referência da fonte. O resultado serve para interpretação humana e nunca é apresentado como causalidade comprovada.

Esta leitura não altera campanhas, públicos, orçamento ou produção e não utiliza dados de clientes, payloads de provedores ou segredos.

```bash
node scripts/preflight-meta-post-execution-observation.mjs --self-test
```
